## Energy manager

Energy market in Greece is a mess. Complicated terms and conditions, different discounts make it impossible for a human being with average inteligence to find the best contract for Energy. 

### Goals:

* Select the best contract for the client every month with the least possible user intervension.
* Calculate the total profit so far based on the average market valie
* Predict user needs based on previous bills per month
* Pay monthly bills with secure and guardrailed way (prepaid card that will be loaded on demand)
* Give useful advice to the user for better energy management

### Priorities

1. Compare only yellow contracts without pre-termination penalty and select the best one
2. Try to apply for the best contract by asking the user all needed informations
3. Store at memory all permenets info so the next time it will be easier to apply
